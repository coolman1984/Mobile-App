# Pixel Plus Owner | تطبيق قيادة الشركة 📱

A **native Android** foundation for the company owner. This is a working **offline demo**, NOT a live licensing app or cloud dashboard. All displayed companies, activation requests and alerts are fictional. No INTERNET permission, server URL, signing key, payment credentials or customer records are included.

## What actually works in this foundation
- Native Arabic right-to-left navigation: Home, Companies, Requests, Alerts and Codes.
- Switch between three **synthetic** companies; all request/alert views are company-scoped.
- Review/deny fake activation requests and mark fake alerts read, entirely in memory.
- Clear disabled real licence-issuance screen; no real code can ever be generated by this build.
- Pure Kotlin tests for company scoping, one-way simulated transitions, invalid IDs and the disabled signer.
- GitHub Actions builds an **unsigned-for-distribution debug demo APK**, intended only for development.

## Build
Open `apps/pixel-plus-owner-mobile` in Android Studio, install Android SDK 35 and JDK 17. Or install Gradle 8.11.1 and run:

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

A GitHub Actions workflow `.github/workflows/pixel-plus-owner-android.yml` runs these checks when mobile files change, and saves a debug APK artifact. This is **not a Play Store release**. There is intentionally no runtime network permission. Do not claim an APK is verified on real Android hardware until installation and smoke tests actually happen.

Build coordinates: AGP 8.9.2 + Gradle 8.11.1 + JDK 17 + Android SDK 35 + Kotlin 2.1.20 + Jetpack Compose. Future updates must keep the tested compatibility matrix.

## Demonstration acceptance
- Home shows 3 companies, 4 sample requests and 3 sample alerts.
- Selecting sample company #2 filters the request/alert lists to only that company.
- Pressing "مراجعة تجريبية" on a demo request changes its status without generating a code.
- Attempting to transition a request from another selected company is refused by the pure state layer.
- The codes tab explicitly says real issuance is locked. App restart resets the demo data.
